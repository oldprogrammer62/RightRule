### The DoesNotContains Operator

## Recognized keywords
- doesnotcontain
- notc

## Usage
*string variable* **doesnotcontain** *"value"*
*string variable* **notc** *"value"*

The Does Not Contain Operator will return true if **value** is not found in **variable**.  
The string comparison is case insensitive.  

## Example (true)
"abcdef" doesnotcontain "xyz"
