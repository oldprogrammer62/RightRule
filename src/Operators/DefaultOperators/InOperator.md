### The Contains Operator

## Recognized keywords
- in

## Usage
*string variable* **in** *[array of strings]*
*int variable* **in** *[array of integerss]*
*double variable* **in** *[array of doubles]*

The In Operator will return true if **value** is found in **[Array]**.  
The string comparison is case insensitive.  

## Example (true)
"a" in ["a","b","c"]
2 in ["1","2","3"]
1.2 in ["1.1","1.2","1.3"]
