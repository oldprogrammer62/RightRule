### The Less Than Operator

## Recognized keywords
- lessthan
- <

## Usage

- ## Number
When both variable and value are numbers  
Example: 10 lessthan 100
- ## Datetime
When both variable and value are Datetime  
"dd.MM.yyyy HH:mm:ss" < "dd.MM.yyyy HH:mm:ss"  
- ## Dateonly
When both variable and value are Dateonly  
"dd.MM.yyyy" < "dd.MM.yyyy"  

Any other types or combinations will return a failure result
