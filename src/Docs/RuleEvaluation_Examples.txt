### Rule Evaluation Methods

RightRuleResult<IProcessedRule> result = rr.ApplyRule("Context");

Which registered data will be available? ALL
Which rules will be applied? All registered rules for the specified "Context".
What will the result object contain?
A single rule will be returned that is either:
- The first rule (ordered numercially, based on Rule Number) to evaluate to true.
- Or, the default rule for the Context.


List<RightRuleResult<IProcessedRule>> result = rr.ApplyRules("Context", EvaluationTypeEnum.ANY);

Which registered data will be available? ALL
Which rules will be applied? All registered rules for the specified "Context".
What will the result object contain?
A set of rules will be returned, dependent on the specified Evaluation Type:
EvaluationTypeEnum.FIRST
Will return a List containing a single rule.
The returned rule will be either:
- The first rule (ordered numercially, based on Rule Number) to evaluate to true.
- Or, the Default rule for the Context.

EvaluationTypeEnum.ANY
Will return a List containing all rules processed.
The result attribute of each rule will indicate rule success.
Each Rule will return either its true Decision details or False Decision details.

EvaluationTypeEnum.ALL
Will return a List containing rules as follows.
All rules applied will be returned only if all rules returned a true result.
The Default rule for the Context will be returned if any rule returns a false result.
