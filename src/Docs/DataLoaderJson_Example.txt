Load Data from JSON
===================
Use LoadData to register one or more datasets from a JSON array.
The example below loads one dataset, reports each registration result, and retrieves the registered datasets.

C# example
----------
using var rr = new RightRule.RightRule();

string json = """
[
  {
    "DatasetName": "Customer",
    "DataItems": [
      {
        "Key": "name",
        "Value": "Alice"
      },
      {
        "Key": "age",
        "Value": 30
      },
      {
        "Key": "isActive",
        "Value": true
      }
    ]
  }
]
""";

var registrationResults = rr.LoadData(json);

foreach (var result in registrationResults)
{
    Console.WriteLine($"{result.Status}: {result.Name} - {result.Message}");
}

var datasets = rr.GetRegisteredData();
Console.WriteLine($"Registered datasets: {datasets?.Count ?? 0}");


JSON format
-----------
The top-level JSON value is an array. Each array item describes a dataset:

- DatasetName: Name used to identify the dataset.
- DataItems: Array of data items belonging to that dataset.
-   Key: Name of a data item.
-   Value: Value associated with that key.

To load multiple datasets, add another dataset object to the array, separated by
a comma. Use valid JSON syntax: property names and string values must be
enclosed in double quotes.

Registration results
--------------------
LoadData returns one DataRegistrationResult for each dataset.
Check Status and Message to determine whether each dataset was registered successfully.

The RightRule instance owns its registered data for its lifetime.
Dispose the instance when the session is finished.
