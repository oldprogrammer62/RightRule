# RightRule developer documentation

RightRule evaluates business rules through a session. Create a session from a `RightRule` instance in a standalone application, or register RightRule with the application's dependency injection (DI) container and resolve an `IRightRuleSession` in a scope.

- [Getting started and configuration](getting-started.md)
- [Sessions and public API](sessions.md)
- [Service reference](service-reference.md)

The examples assume the `RightRule` package and its dependencies are referenced by the application. The public API described here is based on the `RightRule` and `IRightRuleSession` types.
